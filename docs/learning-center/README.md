# Send Koro Learning Center (restaurants)

Short guides with a short video each. They appear on the restaurant welcome page (web and PWA) under **Learning center**, and inside the portal (sidebar → Learning center; PWA → More → Learning center).

Source of truth for the content: `designs/source/restaurant.js` (`LESSONS`). These files are generated from it; edit the source, then regenerate.

Each video plays inside the page: it opens the real portal screens, scrolls to the part being explained, points to it and highlights it, with captions and optional read-aloud (the device’s most natural voice, Slow / Normal / Fast). Full screen is supported. Each lesson also has a video script, so a recorded video with a human voice-over can replace the animation later.
